# Sneaker Store — Telegram Mini App

Интернет-магазин кроссовок в виде Telegram Mini App: клиентское приложение (каталог, корзина, оформление заказа, профиль) и отдельная админ-панель для управления товарами, категориями, баннерами, заказами и настройками магазина.

## Стек

- **Клиент**: React 18 + Vite 5 + Tailwind CSS, React Router v6
- **Сервер**: Node.js + Express 4 (ESM)
- **БД**: PostgreSQL (рекомендуется [Neon](https://neon.tech))
- **Интеграция**: Telegram Web App API + Telegram Bot API (уведомления)

## Структура проекта

```
telegram-mini-shop/
├── client/   # React-приложение (Mini App + /admin)
└── server/   # Express API + работа с БД + бот-уведомления
```

## Требования

- Node.js 20+
- База данных PostgreSQL (например, бесплатный проект на Neon)
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather)

## Настройка сервера

1. Перейдите в папку сервера и установите зависимости:

   ```bash
   cd server
   npm install
   ```

2. Скопируйте `.env.example` в `.env` и заполните значения:

   ```bash
   cp .env.example .env
   ```

   | Переменная | Описание |
   | --- | --- |
   | `BOT_TOKEN` | Токен бота от @BotFather (для отправки уведомлений) |
   | `DATABASE_URL` | Строка подключения к PostgreSQL (для Neon — со `?sslmode=require`) |
   | `ADMIN_PASSWORD` | Пароль для входа в `/admin` |
   | `OWNER_TELEGRAM_ID` | Telegram ID владельца магазина — на этот ID приходят уведомления о новых заказах |
   | `JWT_SECRET` | Случайная строка для подписи токенов админки |
   | `PORT` | Порт сервера (по умолчанию `3001`) |
   | `WEBAPP_URL` | Публичный URL Mini App (опционально, для ссылок в сообщениях бота) |

3. Создайте таблицы в БД:

   ```bash
   npm run migrate
   ```

4. Заполните демо-данными (4 категории, 8 товаров, баннеры, настройки магазина):

   ```bash
   npm run seed
   ```

5. Запустите сервер в режиме разработки:

   ```bash
   npm run dev
   ```

   Сервер поднимется на `http://localhost:3001` (или на порту из `PORT`).

## Настройка клиента

1. Перейдите в папку клиента и установите зависимости:

   ```bash
   cd client
   npm install
   ```

2. (опционально) Скопируйте `.env.example` в `.env`:

   ```bash
   cp .env.example .env
   ```

   По умолчанию `VITE_API_URL` пуст, и клиент ходит на `/api` — Vite dev-сервер проксирует эти запросы на `http://localhost:3001` (см. `vite.config.js`). Для продакшена укажите полный URL вашего API.

3. Запустите дев-сервер:

   ```bash
   npm run dev
   ```

   Откройте `http://localhost:5173` в браузере. Внутри Telegram (Mini App) `window.Telegram.WebApp` будет доступен автоматически; в обычном браузере приложение тоже работает, но без данных пользователя Telegram.

4. Сборка для продакшена:

   ```bash
   npm run build
   ```

   Статика появится в `client/dist` — её можно раздавать любым статическим хостингом (Vercel, Netlify, Nginx и т.д.).

## Админ-панель

Доступна по адресу `/admin` (например, `https://ваш-домен/admin`). Вход — по паролю из `ADMIN_PASSWORD`. Возможности:

- **Товары** — добавление/редактирование/удаление, размеры, цвета, наличие на складе
- **Категории** — добавление/удаление, иконки
- **Баннеры** — слайдер на главной странице
- **Заказы** — список заказов и смена статуса (новый → принят → отправлен → доставлен / отменён)
- **Настройки** — название магазина, реквизиты карты для оплаты, номер Click, описание

## Telegram-уведомления

- При оформлении нового заказа сервер отправляет сообщение владельцу (`OWNER_TELEGRAM_ID`) с деталями заказа.
- При смене статуса заказа в админке клиенту отправляется уведомление в Telegram (если заказ был сделан внутри Mini App и доступен `telegram_user_id`).

Для работы уведомлений обязательно укажите `BOT_TOKEN` и `OWNER_TELEGRAM_ID` в `server/.env`.

## Подключение как Telegram Mini App

1. Разверните `server` (API) и `client` (статика после `npm run build`) на публичных HTTPS-адресах.
2. В `server/.env` укажите `WEBAPP_URL` — публичный URL клиента.
3. Откройте чат с вашим ботом в [@BotFather](https://t.me/BotFather):
   - `/mybots` → выберите бота → **Bot Settings** → **Menu Button** → **Configure Menu Button** → укажите URL клиента (`WEBAPP_URL`) и текст кнопки (например, «Открыть магазин»).
   - Либо используйте `/newapp` для создания полноценного Mini App, привязанного к боту.
4. После этого кнопка меню бота будет открывать Mini App с вашим магазином.

## Полезно знать

- В каждой странице (клиент и админка) есть подпись внизу: «Powered by Finexia · @finexia_uz».
- Цены отображаются в сумах (UZS), формат настраивается в `server/src/constants.js` и `client/src/utils/format.js`.
- Корзина хранится в `localStorage` браузера и сохраняется между сессиями.
